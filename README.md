# TaskFlow

A full-stack task management application built with React, Node.js, Express, and MongoDB.

## Features

- User Authentication: Secure user registration and login using JWT and bcrypt password hashing.
- Task Management: Create, view, update, and delete tasks, with the ability to mark them as Pending or Completed.
- User-Specific Tasks: Each user can access and manage only their own tasks through protected API routes.
